================================================================
功能一：流水文件预处理
================================================================

【按钮名称】
  ▶ 开始预处理（位于"流水预处理"标签页上半部分）

【功能描述】
  将多个账户流水记录混合在同一个 Excel、同一个 Sheet 中时的预处理工具。
  点击后实现：
  1. 自动检测表头行
  2. 自动识别关键列（账户、交易日期、交易时间、余额等）
     兼容多种列名：
       - 账户列：账户 / 账号 / 帐号
       - 日期列：交易日期 / 入帐日期 / 入账日期 / 日期
       - 时间列：交易时间 / 时间
       - 余额列：余额 / 账户余额
  3. 处理"账户号仅在首行出现"的特殊银行流水格式
     （如零余额账户格式，账号出现在第一行数据，后续行均为空）
  4. 按账户分组，每个账户的数据按"交易日期 + 交易时间"从早到晚升序排列
  5. 每个账户写入一个独立 Sheet，Sheet 名为账号
     （Excel 限制 Sheet 名最长 31 字符，非法字符自动替换）
  6. 保存为副本文件，命名规则：原文件名_预处理.xlsx

【操作方法】
  1. 切换到"流水预处理"标签页
  2. 点击"流水文件"旁的"浏览"，选择需要预处理的 Excel 文件
  3. 可选：点击"另存为"指定输出路径（留空则自动生成）
  4. 点击"▶ 开始预处理"
  5. 处理完成后，结果文件自动填入下方的"延迟清算检测"输入框

【处理流程】
  输入文件（单Sheet，多账户混合）        输出文件（多Sheet，各账户独立排序）
  ┌─────────────────┐                  ┌──────────────────┐
  │ 账户A 交易记录1  │   		 预处理       	│ Sheet: 账户A     │
  │ 账户B 交易记录1  │  	 ────────→ 	│  交易记录1（最早）│
  │ 账户A 交易记录2  │                  		    	│  交易记录2        │
  │ 账户B 交易记录2  │                  		    	│  ...             │
  │ ...              │                                                  	│  交易记录N（最晚）│
  └─────────────────┘                  ├──────────────────┤
                                       						│ Sheet: 账户B     │
                                      						│  交易记录1（最早）│
                                       						│  交易记录2        │
                                       						│  ...             │
                                       						│  交易记录N（最晚）│
                                       					└──────────────────┘

================================================================
功能二：延迟清算检测
================================================================

【按钮名称】
  ▶ 延迟清算检测（位于"流水预处理"标签页下半部分）

【功能描述】
  对所有账户、所有日期，筛选出当日最后一笔交易余额不为零的记录。

  核心逻辑：
  1. 读取预处理后的 Excel 文件（也可直接读取任意格式的流水 Excel）
  2. 对每个账户的 Sheet：
     a. 自动识别"交易日期"和"交易时间"列
     b. 按"交易日期"分组
     c. 每个日期内按"交易时间"排序，取当日最后一笔交易
     d. 检查该笔交易的余额是否为零
     e. 若余额不为零 → 记录该条（存在延迟清算嫌疑）
  3. 汇总所有符合条件的记录，按"账户 + 日期"排序输出

【输出结果字段】
  账户        — 账号
  日期        — 交易日（yyyy-mm-dd）
  余额        — 当日最后一笔交易后的余额
  原始日期    — 原始日期数值
  交易时间    — 最后一笔交易的时间
  交易金额    — 最后一笔交易的金额
  对方户名    — 对方户名
  对方行名    — 对方行名
  交易描述    — 交易描述/摘要

【操作方法】
  1. 在"流水预处理"标签页下半部分
  2. 点击"输入文件"旁的"浏览"，选择已预处理的 Excel（或任意流水 Excel）
     （注意：如果刚完成预处理，输出文件路径会自动填入）
  3. 可选：点击"另存为"指定输出路径（留空则自动生成"延迟清算结果.xlsx"）
  4. 点击"▶ 延迟清算检测"
